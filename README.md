# HoverSub

Личная тестовая версия расширения Firefox: перевод отдельного слова при наведении, с опциональной автопаузой (изначально выключена). Интерфейс на русском, по умолчанию английский → русский. Можно выбрать **MyMemory** (бесплатно, без ключа, с лимитами сервиса) или **Google Cloud Translation Basic v2 (NMT)** (свой ключ, биллинг и тарифы Google).

Обновление 0.4.0: нажмите Reload у HoverSub на `about:debugging#/runtime/this-firefox`, затем перезагрузите страницу с видео. Подтвердите доступ к MyMemory, если Firefox его запросит. Выбор сервиса доступен в popup и настройках. При обновлении с 0.3 сохраняются Google, его ключ, согласие и счётчик; для MyMemory нужно отдельное согласие. Для новой установки по умолчанию выбран MyMemory. ZIP: `artifacts/hoversub-0.4.0.zip`.

Кэш разделён по сервисам. Переключение отменяет старые запросы; автоматического перехода при ошибке или исчерпании лимита нет. Google API-ключ отправляется только Google, локальный расход учитывает только запросы Google.

Инструкция Google Cloud — [public/setup.html](public/setup.html), она также доступна из настроек расширения. Ключ нужно вводить только там, не в чат. В этой сессии пользовательский ключ отсутствует: успешный реальный перевод Google еще не проверен.

## Установка для проверки

Нужен Firefox Desktop **142 или новее**.

1. Откройте `about:debugging#/runtime/this-firefox` в Firefox.
2. Нажмите «Загрузить временное дополнение».
3. Выберите `dist/manifest.json` в папке проекта. Если папки dist нет, сначала выполните `npm ci` и `npm run build`.
4. Откройте видео, включите английские субтитры и нажмите значок HoverSub.
5. Выберите MyMemory или Google Cloud. Для Google добавьте API-ключ (Cloud Translation API должен быть включен). Отметьте согласие на передачу слова выбранному сервису и проверьте подключение. Затем нажмите «Включить перевод» для сайта и подтвердите доступ в Firefox.
6. Наведите мышь на слово на 250 мс. При необходимости перезагрузите страницу после первой установки.

Временное дополнение удаляется после перезапуска Firefox. Для постоянной установки обычный Firefox требует подпись Mozilla; эта сборка пока не подписана. ZIP в `artifacts/` — тестовый пакет, а не опубликованное дополнение магазина.

## Как пользоваться

- Языки исходного текста и перевода выбираются в popup. Настройки сохраняются локально.
- По умолчанию видео продолжает играть. С галочкой автопаузы оно останавливается через 250 мс наведения и ждет, пока курсор на словах или карточке. После ухода — продолжает через 300 мс. Перемещение между словами одного видео не вызывает play/pause заново.
- Видео, уже остановленное пользователем, не запускается автоматически. Ручное управление, перемотка, смена источника, отключение расширения и уход в другую вкладку отменяют право на возобновление. Если браузер отклоняет play(), видео остается на паузе без повторных попыток.
- Связь слова с видео определяется в том же документе по расположению. При неоднозначности или недоступном плеере перевод остается доступен без автопаузы; чужие видео на странице не останавливаются.
- При смене реплики карточка закрывается, устаревший ответ игнорируется. Для нового слова нужно движение мыши.
- Переводится доступный текст под курсором, в том числе обычный текст страницы. Чтобы ограничить работу, нажмите «Выбрать область», затем нажмите на контейнер субтитров. Esc отменяет выбор; «Сбросить область» возвращает общий режим. Область действует до перезагрузки/отключения и автоматически сбрасывается при удалении контейнера.
- Если плеер встроен с другого сайта, откройте «Плеер во встроенном окне?» и разрешите только адрес нужного плеера. После загрузки нового iframe список обновится при следующем открытии popup. Доступ к родительскому сайту сам по себе не дает доступа к iframe.
- Выключение на сайте удаляет слой и подписки. Отзыв согласия в настройках прекращает сетевые запросы.
- В настройках можно проверить выбранный сервис на слове dragon, сохранить/удалить ключ, увидеть локальный расход и очистить кэш.

## Совместимость и ограничения

Реализованы общий DOM hit-test без переписывания текста сайта, обработка доступного открытого Shadow DOM, поиск по геометрии для caption-контейнеров YouTube/Video.js/JW Player, интерактивный слой для доступных HTML5 TextTrack и работа разрешенных HTTP(S) iframe.

Это механизм для произвольных сайтов, **не гарантия совместимости с любым плеером**. Реальные проверки перечислены в `docs/QA_REPORT.md`. YouTube предусмотрен в коде, но статус его живой проверки нужно смотреть в отчете, а не выводить из наличия селектора.

Не поддерживаются надписи, вшитые в видеокадр, OCR, недоступный canvas/закрытый Shadow DOM, отдельное окно Picture-in-Picture и защищенные страницы Firefox. В полноэкранном контейнере слой переносится внутрь него. При нативном fullscreen самого `<video>` возвращаются родные субтитры: перевод в этом режиме не обещается. Используйте полноэкранную кнопку контейнера сайта или полноэкранный режим браузера.

В DOM-режиме слово должно целиком лежать в одном текстовом узле. Необычные плееры, делящие слово по буквам на разные элементы, требуют дополнительного адаптера. Для TextTrack поддерживается текст, без сохранения сложного WebVTT-оформления/расположения.

Текст перевода отображается как текст, не как HTML. В MyMemory слово и языки отправляются в параметрах HTTPS-запроса без API-ключа. Для Google слово и языки отправляются в JSON-теле HTTPS-запроса; API-ключ — в X-Goog-Api-Key, без ключа в URL. Google также видит IP. Cookies/referrer отсутствуют. Ключ хранится локально без синхронизации, не включается в пакет и не возвращается интерфейсу после сохранения. Это не зашифрованное хранилище. В приватных окнах тексты не записываются в постоянный кэш; общий числовой расход сохраняется. Политика: `public/privacy.html`.

## Расход

Для NMT Google публикует 500 000 бесплатных символов в месяц ($10 credit), далее $20 за миллион: [тариф](https://cloud.google.com/products/translate/pricing). Локальный предел HoverSub — 450 000 символов за месяц UTC. Счётчик резервируется на диске перед сетью, включает возможные ошибки/отмены и не сбрасывается при очистке кэша или смене ключа. Повторы из кэша сети не требуют. Локальный предел не гарантирует отсутствие списаний в Google: другие приложения/профили, переустановка и расход проекта не контролируются. Нужны отдельный ключ с API restriction и квоты Google; бюджетное уведомление само не отключает оплату.

## Разработка

Node.js 24+, npm. TypeScript, esbuild (четыре самостоятельных IIFE-бандла), Vitest, Mozilla web-ext. Runtime-зависимостей нет.

```powershell
npm ci
npm run test
npm run lint
npm run package
npm run firefox
```

`npm run dev` следит за TypeScript. После изменений в `public/` перезапустите сборку; после изменения manifest перезагрузите расширение. `npm run firefox` использует отдельный временный профиль и требует установленный Firefox в стандартном месте. Нестандартный путь: `npx web-ext run --source-dir dist --firefox "C:/path/firefox.exe"`.

`npm run fixtures` поднимает только локальный стенд на портах 4173 и 4174. Откройте `http://127.0.0.1:4173`: DOM-субтитры, caption с pointer-events:none, нативная дорожка и iframe с другого hostname. Этот стенд не загружает сериалы/внешние видео.

Структура: `src/background.ts` — разрешения, сообщения и настройки; `translation.ts` — API, очередь, кэш; `content.ts` — hover/lifecycle; `detection.ts` — определение слова; `tracks.ts` — TextTrack; `card.ts` — карточка; `popup.ts` и `options.ts` — интерфейс.

Тесты проверяют токенизацию, приватность запросов, ошибки API, кэш, гонки/отмену, квоты, DOM-выбор, безопасный рендеринг и восстановление дорожек. DOM-тесты используют jsdom и не заменяют проверку установленного расширения в Firefox.
