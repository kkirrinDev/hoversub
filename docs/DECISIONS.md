> Актуально для 0.4.0: выбор Google Cloud / MyMemory в popup и настройках. Отдельное согласие и пространство кэша для каждого сервиса. Нет автоматического fallback. Google использует личный ключ и локальный счётчик; MyMemory работает без ключа, с лимитами сервиса. При смене провайдера текущие запросы отменяются. Предыдущие записи ниже описывают историю проекта.

# Решения реализации 0.1.0

## Изменение 0.3.0

По выбору пользователя MyMemory заменён на официальный Google Cloud Translation Basic v2 (API key поддерживается в v2; v3 требует другой авторизации). Ключ передается в X-Goog-Api-Key по [рекомендациям Google](https://docs.cloud.google.com/docs/authentication/api-keys-use), слово — в JSON-теле. Используется NMT; redirect=error, credentials=omit, referrerPolicy=no-referrer.

Личная сборка использует отдельный пользовательский ключ в storage.local. Нет ключа в коде, sync или выдаваемых content script сообщениях. Публичная раздача общего ключа не допускается; для публичного продукта нужно пересмотреть схему доступа. Ключ можно извлечь при доступе к локальному профилю.

При обновлении сбрасывается согласие на прежнего провайдера и удаляется его кэш. Новые ключи кэша имеют префикс google-v2. Локальный счетчик 450 000 символов/месяц UTC сохраняется до запроса и не сбрасывается вместе с кэшем/ключом. Это дополнительный ограничитель одного профиля, не гарантия нулевого счета Google. Нужны облачные квоты и контроль остальных потребителей проекта.

Ниже сохранены исторические решения первой сборки; описание MyMemory и отсутствия ключа заменено изложенным выше.

1. **Универсальная активация.** Разрешения HTTP(S) запрашиваются для выбранного сайта; зарегистрированные content scripts покрывают только выданные origin. Background дополнительно проверяет включение родительского сайта, согласие и разрешение origin текущего frame перед каждым переводом. Домены без адаптера не блокируются.
2. **Автопауза — опция с 0.2.0.** Изначально выключена. Пользователь запросил ее после личной проверки 0.1.0. Контроллер сохраняет владение только своей паузой; ручное управление и смена контекста отменяют возобновление. Обычный режим по-прежнему не вызывает play/pause/seek.
3. **MyMemory без ключа.** Только GET /get, одно слово и языки, credentials=omit, no-referrer. Нет резервного платного провайдера. Не более двух сетевых запросов одновременно, максимум 16 разных ожидающих задач. Тайм-аут 5 секунд, кэш 1 000 записей/7 дней. Приватные обращения не используют постоянный кэш.
4. **esbuild вместо предложенного Vite.** У расширения четыре небольших самостоятельных entrypoint без React и dev-сервера. esbuild прямо выпускает IIFE, подходящие для Firefox background/content scripts; меньше конфигурации и runtime-зависимостей. Версии закреплены package-lock.json.
5. **Firefox 142+.** Manifest V3, background.scripts, декларация websiteContent. Минимальная версия поднята до 142 после проверки web-ext, чтобы декларация сбора данных не давала предупреждений совместимости.
6. **Без обязательных специализированных агентов.** Первая интегрированная версия выполнена основным агентом. Роли из плана остаются доступными для последующих независимых задач; параллельные исполнители не запускались.
7. **Консервативные границы первой сборки.** Нативный fullscreen самого video возвращает исходную дорожку. DOM-слова, разбитые на разные текстовые узлы, и OCR не поддержаны. Матрица реальных проверок в QA_REPORT.md отличает реализацию от подтвержденной совместимости.
