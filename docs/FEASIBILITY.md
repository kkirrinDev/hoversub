# Первичная проверка реализуемости

Дата: 2026-10-05. Расширение еще не реализовано; этот отчет не является приемкой плеера.

## Принятые ограничения

- Обновленный объем: любые сайты с доступными текстовыми субтитрами, включая YouTube. Страница https://dom-drakona.online/episodes/2-seasones-2-seriya/ — пример, а не ограничение продукта.
- Автопауза не нужна: никаких вызовов pause/play или управления временем видео.
- Первая версия бесплатная, без платного ключа и автоматического перехода на платные услуги.

## Целевой плеер

Веб-инструмент не смог получить страницу. Прямой Invoke-WebRequest вернул HTTP 403. Встроенный браузер недоступен, список подключенных браузеров пуст. Защита не обходилась.

Не установлены: провайдер iframe, наличие английской озвучки/субтитров, доступность текста в DOM или TextTrack, режим fullscreen. Поэтому совместимость сайта не заявляется. 403 относится к проверке из среды агента и не означает, что сайт не работает у пользователя.

Для проверки именно этого сайта нужны доступ к странице через подключенный браузер либо сведения о встроенном плеере. Скриншот меню плеера может подтвердить наличие дорожки, но не доступность текста для расширения. По уточнению пользователя эта проверка больше не блокирует разработку универсального механизма и приемку на YouTube.

## Универсальная совместимость

Предлагается общий механизм определения слова в DOM под указателем, без обязательных адаптеров и изменения исходного текста. Для нативных HTML5 TextTrack — собственный интерактивный слой. Встроенные документы обрабатываются content script с учетом разрешений origin. Ручной выбор области помогает при нераспознанном контейнере субтитров.

YouTube включен в обязательную проверку, но еще не проверен. Обещание относится к доступному тексту; вшитые в видеокадр надписи, canvas без доступного текстового источника и закрытые поверхности требуют отдельной технологии. Поддержка всего этого через OCR не включена в MVP.

## Бесплатный перевод

Проверен запрос:

```text
GET https://api.mymemory.translated.net/get?q=dragon&langpair=en%7Cru
HTTP 200
responseStatus: 200
responseData.translatedText: дракон
quotaFinished: false
```

Передавалось только тестовое слово dragon и языковая пара. Ключ, email, аккаунт и платежные данные не использовались. Пользовательские субтитры не отправлялись.

Это основание рассматривать MyMemory как первого кандидата. Один ответ не доказывает качество неоднозначных слов, стабильность, точный размер бесплатной квоты или пригодность к публичному распространению.

Официальные страницы https://mymemory.translated.net/doc/spec.php и https://mymemory.translated.net/doc/usagelimits.php вернули 403 и через веб-инструмент, и через HTTP-клиент. Точные квоты и условия требуют дополнительной проверки; число символов в сутки намеренно не заявлено.

Предлагаемая интеграция отправляет только отдельное слово, без контекста. Повторные запросы кэшируются. При лимите или сбое сервис не заменяется платным; пользователь видит причину, доступные кэшированные переводы продолжают работать.

## Оставшийся риск UX

Без паузы реплика может исчезнуть до завершения перевода. Базовое правило MVP: старый ответ инвалидируется при смене реплики, новый запрос под неподвижной мышью не запускается. После реальной проверки можно отдельно согласовать удержание карточки со старым словом, не вмешиваясь в видео.
