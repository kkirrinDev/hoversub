> Актуально для 0.4.0: выбор Google Cloud / MyMemory в popup и настройках. Отдельное согласие и пространство кэша для каждого сервиса. Нет автоматического fallback. Google использует личный ключ и локальный счётчик; MyMemory работает без ключа, с лимитами сервиса. При смене провайдера текущие запросы отменяются. Предыдущие записи ниже описывают историю проекта.

# HoverSub — перевод субтитров по наведению

Актуализация 0.3.0: по новому решению пользователя провайдер — **Google Cloud Translation Basic v2 (NMT)** с собственным API-ключом и биллингом Google Cloud. Это заменяет прежние требования «MyMemory / без ключа / без платежей» ниже. Бесплатный объём определяется тарифом Google; расширение дополнительно останавливает отправки на 450 000 символах/месяц UTC в одном профиле. В настройках есть поле ключа с сохранением/удалением, счетчик расхода и инструкция. При миграции старое согласие и кэш сбрасываются. Автопауза остается опциональной. Критерий успешного реального перевода Google пока открыт до ввода ключа пользователем. Текущие инструкции: README.md и public/setup.html.

Статус: реализована первая тестовая сборка 0.1.0 универсального расширения для текстовых субтитров. Полная приемка P0 еще не завершена: живая проверка YouTube и других плееров остается открытой. Дата: 2026-10-05. Фактические результаты и ограничения: [QA_REPORT.md](QA_REPORT.md).

Решения пользователя: расширение должно включаться на любых сайтах с субтитрами, включая YouTube; бесплатный перевод. После успешной личной проверки пользователь запросил опциональную автопаузу: с версии 0.2.0 она включается галочкой и изначально выключена. dom-drakona.online — пример использования, а не единственный целевой сайт или зависимость старта.

## 1. Проблема и цель

Пользователь смотрит сериал с оригинальной озвучкой и английскими субтитрами, чтобы улучшать понимание языка. Незнакомое слово заставляет переключаться в переводчик и терять нить разговора. Полный перевод субтитров мешает практике чтения на английском.

Цель: показать перевод конкретного слова прямо рядом с английскими субтитрами при наведении мыши, сохранив контекст просмотра.

Основной пользователь первой версии — автор проекта, Firefox Desktop на Windows. Распространение среди других пользователей — следующий этап.

Основная языковая пара для приемки: английский → русский. Целевой язык выбирается в настройках из реально поддерживаемых провайдером; русский выбран по умолчанию. Произвольные исходные языки и качество всех языковых пар не входят в обещания MVP.

## 2. Пользовательский сценарий

1. Пользователь устанавливает расширение, выбирает язык перевода и разрешает отправку выбранного слова бесплатному сервису. API-ключ для первого варианта не требуется.
2. Открывает сайт с видео, включая YouTube, включает оригинальную озвучку и английские субтитры.
3. Включает HoverSub для сайта и предоставляет необходимый доступ.
4. Наводит курсор на незнакомое слово. Через 250 мс слово подсвечивается; появляется карточка перевода или индикатор загрузки.
5. По умолчанию видео продолжает воспроизводиться. При включенной автопаузе расширение останавливает связанное видео; переход курсора в карточку сохраняет паузу.
6. После ухода курсора с субтитра и карточки карточка закрывается с задержкой 300 мс. При смене реплики старое наведение сбрасывается, а карточка закрывается; вариант удержания карточки можно добавить после проверки удобства.
7. Повторное обращение к тому же слову в том же контексте использует кэш.

Пример: наведение на dragon показывает «дракон». Перевод предложения целиком не заменяет исходные субтитры. Первая версия переводит отдельное слово без контекста: для missed или идиом результат может не соответствовать смыслу реплики. Контекстный перевод — последующее улучшение.

## 3. Объем MVP

### Обязательно — P0

- Firefox Desktop, включение и выключение для конкретного сайта.
- Выбор целевого языка и явный исходный язык EN; язык дорожки можно использовать, когда он известен.
- Перевод отдельного слова без клика и выделения.
- Карточка рядом со словом: исходное слово, перевод, загрузка, понятная ошибка и повтор запроса.
- Непрерывное воспроизведение по умолчанию; отдельная галочка включает паузу на время наведения. Перемоткой расширение не управляет.
- Сохранение настроек, локальный ограниченный кэш и очистка кэша.
- Активация на произвольном обычном веб-сайте после выдачи доступа, без списка разрешенных брендов плееров.
- Общий механизм определения текстового слова под курсором в DOM: работает с субтитрами, представленными текстом, без обязательного адаптера сайта. На произвольной странице этот механизм может также реагировать на обычный текст; для ограничения областью субтитров предусмотрен ручной выбор области.
- Доступные HTML5 TextTrack отображаются отдельным интерактивным слоем, поскольку нативные субтитры не являются обычными DOM-словами.
- YouTube входит в обязательную приемку: обычные и автоматически созданные субтитры, когда они доступны на видео. Специальный адаптер добавляется только если общего механизма недостаточно.
- Нормальный, театральный и полноэкранный режимы проверенных плееров; ограничения отдельных режимов указываются явно.
- Правильная обработка смены реплики, языка, видео, серии и SPA-навигации.
- Ограничения разрешений и прозрачное раскрытие передачи текста внешнему переводчику.
- Реальные запросы к подключенному сервису в рабочей сборке; тестовые ответы допустимы только в тестах.

### После MVP — P1

- Выделение фразы мышью и перевод фразовых глаголов/идиом. Отдельное слово не всегда передает смысл выражения.
- Словарь сохраненных слов, экспорт, примеры и произношение.
- Импорт SRT/VTT с настройкой сдвига времени как запасной способ для неподдерживаемых сайтов.
- Улучшения совместимости с нестандартными плеерами, режим активации по клавише-модификатору.
- Клавиатурный выбор слов непосредственно в субтитрах.
- Контекстный перевод с отдельным выбором провайдера и раскрытием передачи реплики.

### Не входит в первую версию

- OCR надписей в кадре, распознавание речи, генерация субтитров.
- Перевод всей страницы, дубляж, замена английских субтитров русскими.
- OCR-субтитры и недоступные для расширения защищенные поверхности; Chrome, Firefox Android, отдельное окно Picture-in-Picture.
- Аккаунты, подписки, синхронизация, серверная история просмотров.
- Обход DRM или ограничений доступа к контенту.

## 4. Совместимость и технические ограничения

| Источник субтитров | Решение | Обязательство MVP |
| --- | --- | --- |
| Доступные HTML5 TextTrack/VTTCue | Чтение активных реплик и собственный интерактивный слой | Тестовый HTML5-плеер |
| Текст субтитров в DOM | Общий поиск текстового слова под курсором и его геометрии; ручная область при необходимости | Универсальный механизм, обязательная проверка YouTube и независимых DOM-fixtures |
| Плеер во frame другого origin | Отдельный content script при наличии разрешения на origin, обмен сообщениями | Общая поддержка доступных iframe; без разрешения объяснить необходимость доступа |
| Canvas, изображения, вшитые надписи | Нет текстового источника; нужен OCR или внешний файл | Не поддерживается |
| Закрытые компоненты, недоступные дорожки | Исследование сайта и документированный статус | Без обещания автоматической поддержки |

Доступ к `video.textTracks` предусмотрен платформой, но это не означает, что любой сервис публикует свои субтитры через него. Основание: [MDN: textTracks](https://developer.mozilla.org/en-US/docs/Web/API/HTMLMediaElement/textTracks).

Область продукта — любые сайты с доступными текстовыми субтитрами, включая YouTube. Архитектура не должна требовать добавления домена в код для базового перевода DOM-текста. Абсолютную совместимость с любым способом вывода надписей нельзя подтвердить конечным набором проверок; приемка проводится по типам источников и конкретным контрольным сайтам.

Пример пользователя: https://dom-drakona.online/episodes/2-seasones-2-seriya/ . При проверке прямой HTTP-запрос вернул 403, веб-инструмент не смог открыть страницу, подключенные браузеры отсутствуют. Устройство этого плеера пока неизвестно. Это не блокирует разработку универсального механизма; сайт остается отдельным непроверенным примером в матрице совместимости.

Матрица совместимости содержит: сайт или fixture, тип субтитров, поддерживаемые режимы, версии Firefox, дату проверки и ограничения. При отсутствии обнаруженной дорожки общий DOM-режим остается доступным. Нельзя объявлять сайт неподдерживаемым только из-за отсутствия специального адаптера. Для недоступного источника показать «Текст субтитров недоступен» с возможностью проверить разрешения или выбрать область вручную.

## 5. Функциональные требования и приемка

| ID | Требование | Проверяемый результат |
| --- | --- | --- |
| F01 | Управление активацией | При выключении исчезают слои и наблюдатели, новые запросы не отправляются; исходное состояние субтитров восстановлено |
| F02 | Настройки языка | Выбор сохраняется после перезапуска, старый ответ не показывается после смены языка |
| F03 | Определение слова | Учитываются апострофы, сокращения, дефисы, переносы и знаки препинания; наведение на пробел не вызывает запрос |
| F04 | Наведение | До истечения 250 мс запросов нет; движение внутри одного слова не создает повторы |
| F05 | Карточка | Не выходит за границы видимой области плеера, по возможности не закрывает строку и контролы; переход мыши в карточку ее не закрывает |
| F06 | Асинхронность | Ответ для слова A никогда не заменяет карточку слова B; каждый запрос связан с сессией плеера, репликой, словом и языками |
| F07 | Опциональная автопауза | Выключена по умолчанию. При включении останавливает только связанное игравшее видео и продолжает после ухода со слова/карточки; ручное управление, смена источника и деактивация отменяют автовозобновление |
| F08 | Без автопаузы | Смена реплики закрывает старую карточку и инвалидирует ее запрос; устаревший перевод не привязывается к новому слову |
| F09 | Ошибки | Различаются отсутствие сети, лимит бесплатного сервиса, неподдерживаемый язык и тайм-аут; воспроизведение не блокируется ошибкой, платного переключения нет |
| F10 | Кэш | Повтор в том же контексте не делает сеть; смена провайдера, языков или контекста не использует неподходящий результат |
| F11 | Fullscreen | В проверенном режиме карточка видна и интерактивна после входа и выхода; неподдерживаемый режим явно указан |
| F12 | Жизненный цикл | Перемотка, смена дорожки/эпизода и навигация очищают прежние подписки и не создают дублирующих слоев |
| F13 | Разрешения | Отказ или отзыв доступа корректно отключает возможности; доступ к другим сайтам автоматически не запрашивается |
| F14 | Минимизация данных | Отправляется только выбранное слово и языковая пара, без реплики, URL страницы и истории |
| F15 | Произвольный сайт | На тестовом домене без адаптера переводится DOM-слово под курсором; список поддерживаемых сайтов не ограничивает активацию |
| F16 | Встроенный плеер | В доступном cross-origin iframe наведение работает после выдачи доступа его origin; при отсутствии доступа есть понятное сообщение |
| F17 | Ручная область | Если автоматическое определение субтитров не сработало, пользователь может выбрать их контейнер; вне него запросы не выполняются, отмена выбора доступна |
| F18 | YouTube | Перевод работает на обычных и автоматических субтитрах доступных контрольных видео, при SPA-переходе и смене режимов просмотра |

Автопауза добавлена в 0.2.0 по запросу пользователя. Контроллер владеет только собственной паузой; уже остановленное видео не запускает. Ручные действия и медиасобытия, меняющие контекст, отменяют владение. Если связанное видео нельзя однозначно определить, пауза не выполняется. При смене реплики наведение инвалидируется; слово из следующей реплики под неподвижным курсором не вызывает новый запрос до движения указателя.

## 6. UX

Popup: переключатель для сайта, статус поддержки, язык перевода, галочка автопаузы, переход к настройкам. Настройки: те же языки и автопауза, сведения о бесплатном сервисе, проверка подключения, разрешение передачи слова, очистка локальных данных. Поля ключа нет.

Карточка компактная, с контрастным фоном и крупным читаемым переводом. Исходный текст остается английским. Никакого постоянного русского второго ряда. Esc закрывает карточку; элементы настроек доступны с клавиатуры и имеют подписи. Ошибки не обозначаются одним цветом.

Для DOM-субтитров исходный текст не заменяется и не разбивается путем переписывания DOM: слово и прямоугольники определяются по текстовому узлу и Range, карточка рисуется отдельно. Для TextTrack оригинальные субтитры скрываются только после успешного запуска собственного слоя и обратимым способом. Адаптер сохраняет исходное состояние и восстанавливает его при отключении. Слой перехватывает указатель только на словах и карточке, сохраняя работу остального плеера.

Fullscreen требует отдельной проверки: положение слоя зависит от `document.fullscreenElement`. Полноэкранный контейнер плеера и нативный полноэкранный `<video>` проверяются отдельно; одного высокого `z-index` недостаточно. Основание: [MDN: fullscreenElement](https://developer.mozilla.org/en-US/docs/Web/API/Document/fullscreenElement).

## 7. Перевод и расходы

Пользователь выбрал бесплатный вариант. Первый кандидат — MyMemory, без ключа, регистрации, нашего backend и автоматического перехода на платный тариф. Выполнен реальный GET-запрос к `https://api.mymemory.translated.net/get` с `q=dragon` и `langpair=en|ru`: HTTP 200, responseStatus 200, translatedText «дракон», quotaFinished=false. Это подтверждает один рабочий перевод, но не стабильность и качество всех слов.

Официальные страницы [API](https://mymemory.translated.net/doc/spec.php) и [лимитов](https://mymemory.translated.net/doc/usagelimits.php) при проверке возвращали 403. Поэтому точная дневная квота и условия использования пока не подтверждены. Не обещать безлимитность; окончательно закрепить провайдера после проверки условий. Не использовать недокументированные endpoints веб-переводчиков. Подробности: [FEASIBILITY.md](FEASIBILITY.md).

Запрос MVP: только слово и языки. Ответ: перевод, опциональные альтернативы, явный режим «без учета контекста». Языки кроме EN→RU добавляются в список после smoke-проверки. При исчерпании бесплатной квоты показывается ошибка, кэш продолжает работать; платные запросы не выполняются.

Плановые ограничения: максимум 2 одновременных сетевых запроса на расширение, объединение одинаковых запросов, очередь только актуальных обращений, отмена устаревших запросов где возможно. Автоматических бесконечных повторов нет. Кэш: не более 1 000 записей, TTL 7 дней, LRU-вытеснение. Ключ кэша включает провайдера/модель, языки, нормализованное слово и контекст при его использовании. Самостоятельно переводить каждую реплику заранее запрещено.

Пользовательские платежи в MVP отсутствуют. Измерять количество уникальных запросов за час для оценки достаточности бесплатной квоты. Локальный счетчик обращений не требует внешней аналитики.

## 8. Архитектура и требования к разработке

Предлагаемый стек: TypeScript со strict-проверками, WebExtensions Manifest V3, Vite для сборки, обычный DOM/CSS для небольшого UI, Vitest для логики, `web-ext` для запуска, lint и упаковки. Номера версий закрепить lockfile на старте реализации.

Firefox использует `background.scripts` и непостоянную фоновую страницу; нельзя строить архитектуру только на Chrome service worker. Настройки и необходимое долговременное состояние сохраняются в storage. Источник: [MDN: background](https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/manifest.json/background).

Поток данных:

```text
Адаптер субтитров → активная реплика → интерактивный слой → наведение
                                                        ↓
                    карточка ← background: кэш / очередь / провайдер

                    смена реплики → сброс наведения и старого ответа
```

Границы модулей:

- `adapters`: общий DOM-источник, HTML5 TextTrack, обнаружение плеера/реплик, контейнер, возможности, подписка/отписка. Дополнительные адаптеры улучшают совместимость конкретных плееров, но не являются условием активации сайта.
- `content/detection`: слово под координатами указателя, текстовый Range, выбор области, привязка к документу/frame. Работа с открытым Shadow DOM проверяется отдельно; закрытые недоступные поверхности не обещаются.
- `content`: токенизация, интерактивные субтитры, геометрия карточки, lifecycle. Стили изолированы, например через Shadow DOM. Управление воспроизведением отсутствует.
- `background`: сетевые запросы, проверка сообщений, бесплатный провайдер, кэш, ограничения частоты. Секреты для первого варианта не нужны.
- `popup` и `options`: управление и настройка.
- `shared`: типы сообщений, настроек, реплик, возможностей и ошибок.
- `tests/fixtures`: легальные собственные образцы видео/субтитров и HTML-плееры для воспроизводимых проверок.

Content script общается с background через типизированные сообщения с runtime-валидацией. Произвольный URL из сообщения не превращается в сетевой запрос; endpoint ограничен выбранным провайдером. Сетевые обращения идут из background с нужными разрешениями. [MDN: content scripts](https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/Content_scripts).

Наблюдатели ограничены найденной или выбранной областью. Общий DOM-режим использует поиск под координатами указателя, не сканирует весь документ на каждом `mousemove` и не делает бесконечный polling. Поля ввода, contenteditable и UI расширения исключены из перевода. Обработчики, таймеры и слой удаляются при деактивации и смене сессии.

## 9. Приватность и безопасность

- Запрашивать доступ к сайту по явному действию пользователя, с отдельным учетом origin встроенного плеера. Основание: [MDN: optional_host_permissions](https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/manifest.json/optional_host_permissions).
- До первой отправки объяснить, что выбранное слово и языковая пара передаются MyMemory, а сервис видит IP сетевого соединения. Учесть актуальные требования Firefox к декларации передаваемых данных и согласию. [Mozilla: Add-on Policies](https://extensionworkshop.com/documentation/publish/add-on-policies/).
- Не передавать видео, аудио, cookies, URL страницы или историю просмотра. Не включать внешнюю аналитику в MVP.
- API-ключи и платежные данные в MVP не собираются. Если платные провайдеры появятся позже, управление ключами проектируется отдельно.
- Весь внешний текст выводится как текст, без исполнения HTML; код поставляется в пакете расширения.
- Для приватных окон — без постоянного кэша и истории, если пользователь отдельно разрешил расширению работу в них.
- Локальный кэш может содержать текст переводов; очистка доступна пользователю. Логи ошибок исключают ключи и полные реплики.

## 10. Нефункциональные требования

Это целевые показатели приемки, а не уже измеренные результаты:

| Показатель | Цель и способ проверки |
| --- | --- |
| Локальный отклик | P95 показа карточки из кэша ≤100 мс после выдержки наведения; 100 обращений на согласованной машине |
| Сетевой перевод | Целевой P95 ≤2 с после запуска запроса на 100 обращениях; сеть и провайдер фиксируются в отчете |
| Тайм-аут | Через 5 с понятная ошибка без зависшего индикатора и блокировки плеера |
| Производительность | Нет длинных задач >50 мс, вызванных расширением, в 10-минутном профиле тестового плеера |
| Стабильность | 30 минут просмотра и 20 смен ролика/режима без дублирования слоев и накопления активных подписок |
| Качество перевода | Минимум 85 из 100 заранее размеченных примеров EN→RU признаны приемлемыми пользователем; обычные слова и неоднозначные случаи отчетливо разделены |
| Совместимость | Реальный Firefox Stable на Windows; версию и минимальную поддерживаемую версию записать по результатам прототипа |

Если провайдер не достигает сетевой цели, решение о смене провайдера или изменении требования принимается явно. Качество контекстного перевода проверяется отдельно от точности определения слова под курсором.

## 11. Проверки и критерии готовности

Unit: токенизация, состояние наведения, актуальность ответа, ключи кэша, отсутствие управления воспроизведением, ошибки и лимиты.

Integration: реальные DOM-реплики и смена cue, несколько видео, смена языка, race между запросами, отключение на лету, восстановление субтитров, повторный запуск background.

Браузерные проверки: расширение действительно загружается в Firefox через `web-ext`; одного теста страницы в браузере недостаточно. Возможный автоматизированный harness выбирается после прототипа. Запуск Firefox в Playwright сам по себе не доказывает работу установленного WebExtension.

Ручная приемка на выбранном сайте: hover во время непрерывного просмотра, видео уже остановлено, ручная пауза, перемотка, fullscreen, масштаб страницы 125–150%, смена серии, потеря сети, отозванное разрешение, лимит бесплатного API, закрытие вкладки. Отдельно: реплика меняется во время медленного запроса, неподвижный курсор над новой репликой не запускает запрос сам.

Готовность MVP:

1. Все P0 выполнены на HTML5 TextTrack-плеере, независимых DOM-fixtures (в том числе iframe другого origin) и YouTube. Активация на новом домене не требует изменения исходников. dom-drakona.online проверяется при появлении доступа; до этого статус явно «не проверен».
2. Нет критических дефектов: чужой перевод в карточке, вмешательство в воспроизведение, отправка лишних данных, сломанные субтитры после отключения.
3. Пройдены typecheck, lint, unit/integration, `web-ext lint`, ручная приемка Firefox и реальный smoke-запрос к провайдеру.
4. Есть воспроизводимая сборка, устанавливаемый тестовый пакет, инструкция и матрица совместимости.
5. Зафиксированы измерения задержки и качества. Известные ограничения указаны явно.

Публикация в Mozilla Add-ons — отдельный этап после личной приемки. Временная установка для разработки и подписанный пакет для обычного использования описываются отдельно. Инструменты: [Mozilla: web-ext](https://extensionworkshop.com/documentation/develop/getting-started-with-web-ext/).

## 12. Открытые решения

| Решение | Предложение | Статус |
| --- | --- | --- |
| Сайты первой версии | Любые сайты с доступным текстом; YouTube в обязательной приемке | Решение пользователя; dom-drakona.online — дополнительный пример, пока не проверен |

| Контекст | Перевод одного слова, без реплики | Ограничение предлагаемого бесплатного MVP |
| Публикация | Сначала личная сборка, затем Mozilla Add-ons | Предлагаемый порядок |

Направление уточнено пользователем. Следующий шаг — универсальный прототип DOM-наведения, TextTrack-слоя и бесплатного перевода; затем проверка в Firefox и на YouTube. Доступ к одному конкретному сайту больше не является условием старта. HTTP 403 не считать доказательством совместимости или несовместимости dom-drakona.online.
