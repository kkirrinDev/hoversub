# HoverSub 0.1.0 — отчет проверки

## Обновление 0.3.0 — Google Cloud

MyMemory заменён на Google Cloud Translation Basic v2, модель NMT. Реальный endpoint: POST https://translation.googleapis.com/language/translate/v2, JSON q/source/target/format/model, ключ в заголовке X-Goog-Api-Key. В manifest оставлен только Google как обязательный host API; MyMemory не является fallback.

43 автоматических теста в 6 файлах. Добавлены проверки официального формата Google, отсутствия ключа в URL/теле и сообщениях состояния, отказа без ключа, обработки Google quota/403, безопасного декодирования entities, миграции согласия и кэша, сохранения расхода при удалении ключа, атомарной очереди резервирования на границе 450 000 символов, смены месяца UTC и отказа при невозможности записать счётчик. Контракт Google в тестах имитируется; пользовательский ключ отсутствует, **успешный запрос к реальному Google API не выполнен**.

Подключение полностью подготовлено в настройках: ввод/удаление ключа, новое согласие, кнопка проверки, счётчик расхода и встроенная инструкция setup.html. Для проверки пользователь должен включить Cloud Translation API и биллинг в своём проекте, ограничить ключ этим API и ввести его локально в расширение.

Пакет: artifacts/hoversub-0.3.0.zip. Старые отчеты MyMemory ниже относятся к прежним версиям и не подтверждают качество/доступность Google-интеграции.

## Обновление 0.2.0

Пользователь проверил 0.1.0 на видео и прислал скриншот успешного перевода sequence → последовательность из кэша; подтвердил, что успевает прочитать карточку. Это пользовательское подтверждение основного сценария, не полный прогон матрицы сайтов.

По новому запросу добавлена галочка автопаузы в popup и настройки, выключенная по умолчанию. Пауза после выдержки наведения 250 мс; удерживается при переходе между словами того же видео и в карточку, возобновляется после ухода с задержкой закрытия 300 мс. Ручное управление, медиасобытия изменения источника/состояния, удаление video, деактивация и потеря фокуса отменяют право на автовозобновление.

Пройдены 33 автоматических теста в 5 файлах и TypeScript/web-ext lint без ошибок и предупреждений. Новые 13 сценариев: миграция настройки, удержание паузы, видео уже остановлено, ручное управление, seeking/emptied/ended/play/ratechange, выключение/удаление, замена источника, отказ play(), выбор связанного видео. Тесты playback используют jsdom и mock media methods; живая проверка новой галочки в плеере остается необходимой.

Пакет: `artifacts/hoversub-0.2.0.zip`. Для обновления временного дополнения — Reload в about:debugging, затем перезагрузка видео-страницы. Проверка данных/бесплатности/квот: [TRANSLATION_SECURITY.md](TRANSLATION_SECURITY.md).

| Настоящий Firefox | Firefox Developer Edition 158.0, headless, отдельный временный профиль; web-ext сообщил успешную установку временного дополнения |

Тесты покрывают отмену предыдущего слова, совместное использование одного запроса разными frame, ограничение параллельности до двух, отмену очереди, тайм-аут, приватный режим без постоянного кэша, разделение языков, TTL/LRU, ошибки квоты/ответа, отсутствие cookies/referrer, фильтрацию входных данных, запрет настройки из content script и сети без согласия, DOM-геометрию/редактируемые поля, устаревшую реплику, безопасный вывод текста, восстановление native tracks и отсутствие вызовов play/pause.

DOM и TextTrack проверены в jsdom с имитацией геометрии/медиа. Это не заменяет аппаратный браузерный рендеринг или проверку реального видео. Запуск Firefox подтвердил установку пакета, но не end-to-end наведение, разрешения popup или сетевой запрос из background.

## Открытые проверки перед заявлением о готовности MVP

- Firefox Stable (найденный и использованный установленный браузер — Developer Edition).
- Установка/включение через popup и фактический перевод по наведению на YouTube с обычными и автоматическими субтитрами.
- Выдача, отказ и отзыв host-разрешений, включая iframe другого сайта.
- Визуальное положение карточки: края, масштаб 125–150%, fullscreen, переход мыши в карточку.
- Смена языка/видео/серии, выключение на лету, приватное окно, медленная сеть на настоящем видео.
- 30-минутная сессия, профиль производительности, 100 запросов для задержки и 100 размеченных примеров качества.
- Проверка точных бесплатных лимитов и условий сервиса перед публичной публикацией.

## Зависимости

Runtime npm-зависимостей нет: в пакет включены собственные собранные скрипты и статические файлы. `npm audit` обнаружил цепочку из трех high-записей в инструментах разработки: web-ext → @devicefarmer/adbkit → node-forge 1.4.0 (GHSA-86w9-cpqp-85rv). Последняя доступная при проверке версия node-forge — 1.4.0. Автоматическое предложение audit — откат web-ext до 5.1.0 — не применено, поскольку он не соответствует актуальной MV3-проверке. Уязвимая зависимость не попадает в ZIP и не используется расширением; Android/ADB не использовались. Перепроверить инструментарий перед публикацией.

## Артефакты и воспроизведение

- `dist/manifest.json` — выбрать в Firefox `about:debugging#/runtime/this-firefox` → «Загрузить временное дополнение».
- `artifacts/hoversub-0.1.0.zip` — неподписанный тестовый пакет.
- `npm run fixtures` — локальные DOM/TextTrack/iframe примеры на http://127.0.0.1:4173 .
- Команды проверки: `npm run test`, `npm run lint`, `npm run package`.
- Запуск с найденным браузером: `npx web-ext run --source-dir dist --firefox "C:/Program Files/Firefox Developer Edition/firefox.exe" --args=-headless --no-reload --no-input --start-url about:blank`.

Попытка загрузить отдельный Firefox Stable скачала установочный файл, но автоматическая распаковка не завершилась и была остановлена. Для smoke-проверки использован уже установленный Developer Edition без обращения к пользовательскому профилю. Управляемого browser UI в инструментах сессии нет, поэтому визуальная проверка не заявляется.
