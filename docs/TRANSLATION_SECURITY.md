# MyMemory: проверка интеграции 0.2.0

## Актуализация 0.3.0 — Google Cloud

Этот документ ниже сохраняет историю MyMemory. С 0.3.0 сетевой провайдер — Google Cloud Translation Basic v2; обращений к MyMemory и fallback больше нет. Слово/языки отправляются в JSON-теле HTTPS POST, ключ — в X-Goog-Api-Key. Не отправляются cookies, referrer и видео; сервер Google видит IP, ключ проекта и текст.

Ключ хранится в storage.local без sync, не возвращается в state/active и не включается в пакет. Поле ввода очищается после сохранения; локальный профиль не является зашифрованным сейфом. Удаление из расширения не отзывает ключ в Google. Для личной сборки нужен отдельный ключ с API restriction Cloud Translation и облачные квоты. Для публичной раздачи общего ключа схема не подходит.

Google публикует [условия данных](https://docs.cloud.google.com/translate/data-usage): кратковременная обработка текста в памяти, без использования для обучения. [Тариф NMT](https://cloud.google.com/products/translate/pricing): первые 500 000 символов/месяц как $10 credit, затем $20/млн. Требуется биллинг. Счетчик HoverSub 450 000/месяц UTC ограничивает один профиль, не гарантирует отсутствие списаний в Google. В приватных окнах сохраняется только общий числовой расход, не слова. Официальный запрос еще не проверен с пользовательским ключом.

Проверены исходники `translation.ts`, `background.ts`, `shared.ts`, интерфейс согласия и политика данных. Это целевая проверка интеграции, а не независимый аудит безопасности всего расширения или инфраструктуры MyMemory.

## Данные и защита

- Запрос по HTTPS к фиксированному `https://api.mymemory.translated.net/get`.
- Только `q` (выбранное слово) и `langpair` (языки). Произвольный URL из страницы не принимается.
- Cookies отключены (`credentials: omit`), referrer страницы не отправляется (`no-referrer`). Нет API-ключа, email, аккаунта или платежных реквизитов.
- Сервер видит слово, языки, IP и обычные технические данные HTTP-соединения. Слово передается в query string GET-запроса; оно может попасть в журналы на стороне сервиса. HTTPS защищает передачу, но не скрывает слово от самого провайдера.
- Нет сети без согласия, включения сайта и разрешений Firefox. Content script не может изменить настройки через сообщения background.
- Ответ выводится через textContent; присланный HTML не исполняется.
- Локальный кэш: до 1 000 записей, TTL 7 дней, очистка доступна в настройках; это обычное хранилище профиля, не зашифрованный сейф. В приватных окнах постоянный кэш не используется.
- Общий режим умеет переводить обычный текст страниц, поэтому на конфиденциальных страницах расширение лучше выключать или ограничивать областью субтитров. Поля ввода и contenteditable исключены из hit-test.

Срок хранения GET-запросов у MyMemory, доступ сотрудников, использование для обучения и правила удаления **не подтверждены**. Общую политику translated.com нельзя автоматически применять к MyMemory: она отдельно ограничивает свою область действия. Утверждений «ничего не хранится» или «полностью анонимно» не делаем.

## Бесплатность и ограничения

Текущая реализация работает с анонимным endpoint без ключа. Повторная проверка dragon → дракон: HTTP 200, quotaFinished=false. Платных SDK, аккаунта, платежного метода и автоматического переключения в коде нет. Исчерпание квоты обрабатывается как ошибка; кэш доступен дальше.

Официальные страницы https://mymemory.translated.net/doc/usagelimits.php и https://mymemory.translated.net/doc/spec.php повторно вернули 403. Ответ рабочего API не содержал заголовков с точным лимитом или остатком. Поэтому **точную актуальную дневную квоту не удалось подтвердить**. В сторонних описаниях встречаются противоречивые единицы и числа, в продукт их не переносим. Доступность и условия бесплатного сервиса могут изменяться независимо от расширения.

Собственные ограничения расширения: 2 одновременных запроса, не более 16 различных задач, одно слово длиной до 80 UTF-16 единиц, тайм-аут 5 секунд. Кэшированные повторы не создают новый сетевой запрос. Это ограничения клиента, не обещание квоты MyMemory.

Качество: одно слово переводится без предложения; фразовые глаголы, омонимы, сленг и названия могут переводиться неправильно. Оценки качества на большой выборке пока нет.
