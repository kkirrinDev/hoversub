Подключение Google Cloud

HoverSub 0.3.0 использует официальный Cloud Translation Basic API v2 (NMT). Создайте отдельный ключ для проекта с включенным Cloud Translation API. JSON сервисного аккаунта сюда не подходит.

  1. Создайте или выберите отдельный проект в Google Cloud Console.
  2. Подключите биллинг по инструкции Google. Доступность регистрации и способов оплаты зависит от страны и аккаунта.
  3. В APIs & Services → Library включите Cloud Translation API (translation.googleapis.com).
  4. В APIs & Services → Credentials создайте API key. В API restrictions ограничьте его только Cloud Translation API. Ключ не публикуйте и не передавайте в чат.
  5. В настройках HoverSub вставьте ключ, нажмите «Сохранить ключ», разрешите передачу слова Google и нажмите «Проверить: dragon → дракон».
  6. Откройте видео, включите HoverSub для сайта и выберите языки. MyMemory больше не используется.

Контроль расходов

Для NMT Google публикует бесплатный объём 500 000 символов в месяц ($10 credit), далее $20 за миллион. Проверить актуальную цену.

В Google Cloud → Cloud Translation API → Quotas настройте доступные квоты символов/запросов; создайте уведомления Billing → Budgets & alerts. Уведомление бюджета само по себе не останавливает расходы. HoverSub дополнительно блокирует отправки после 450 000 символов за месяц UTC в одном профиле. Это не общий предел расходов проекта.

Ограничения ключа

Запрос идёт из фонового процесса без Referer страницы. Ограничение ключа адресом YouTube или сайта с сериалом не подходит: это не источник запроса. Если нужна строгая привязка ключа к приложению, нужен отдельный доверенный сервер; общий секрет нельзя безопасно раздавать в публичном расширении. Для личной сборки используйте отдельный ключ только для Translation API и ограниченные квоты. Не снимайте ограничения с ключа других приложений.

Ключ хранится локально в профиле Firefox; при доступе к профилю его можно извлечь. Удаление ключа из HoverSub не отзывает его в Google: для отзыва удалите ключ в Cloud Console.

Если перевод не работает

  • 403: проверьте включение API, биллинг и ограничения ключа.
  • 400/401: проверьте ключ и языки.
  • 429: превышена квота Google.
  • Локальный предел: до следующего месяца доступны переводы из кэша.

Не отправляйте ключи в скриншотах и сообщениях об ошибках. Подробные ошибки Google намеренно не выводятся в карточке.
